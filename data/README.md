# Data

`contracts.json` — 14 synthetic French public procurement contracts
(structured JSON: buyer, winner, amount, CPV, dates, description).
Same corpus as the `decp-contracts-rag` project, so the two approaches
can be compared on identical ground.

`graph.json` — the built knowledge graph (nodes, edges, Louvain
communities, summaries). Generated by `python scripts/build_graph.py`,
gitignored, rebuilt deterministically (seed 42).
